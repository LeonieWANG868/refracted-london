      Data & methodology

      Every journey refracts our understanding of the city.

      Distance and travel time
      Great-circle distance between TfL StopPoint coordinates, using a 6,371.0088 km mean Earth radius. Travel time uses the first plan returned for each archived TfL Journey Planner request.
      Optical path
      The beam is an artistic interpretation inspired by Fermat’s principle. Travel minutes set the pacing, and a transfer briefly changes the light intensity. For the small colour split inside the glass, the duration is divided by the greater of the direct distance and 0.75 km. This ratio maps from 1–6 min/km to a capped 0–100% effect.
      Transport projection
      The stationary map uses TfL leg geometry and line colours. Nodes follow the Journey Planner stop sequence and use TfL StopPoint coordinates. Dashes indicate walking or interpolation through verified stops if detailed geometry is unavailable. Moving light suggests journey direction. The data comes from archived plans.
